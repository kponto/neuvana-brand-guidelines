# How to prompt

These instructions are for humans. Paste only the files listed for the task, and always include `verbal/constraints.yaml`.

## Opening lines to paste with any task

> Use only the attached brand files. If anything you need is marked [INCOMPLETE], stop and tell me instead of filling it in. Before returning a draft, check it against the tests in voice-and-tone.md and the never_say list in constraints.yaml, and list anything that needs claims review.

## Files by task

| Task | Paste |
|---|---|
| Social post (copy) | constraints.yaml, voice-and-tone.md, messaging.md, audience.yaml (name the segment) |
| Social post (image) | Add art-direction.md or art-direction-graphics.md, plus visual-system.json |
| Meta ad | Social post files plus messaging-objections.md (Meta channel rules) |
| Product page | constraints.yaml, positioning.md, messaging.md, messaging-objections.md, voice-and-tone.md, terminology.yaml; for layout add visual-system.json and logo.md |
| Email | constraints.yaml, voice-and-tone.md, messaging.md, audience.yaml. Email rules are [INCOMPLETE]. |
| App UI copy | constraints.yaml (correlation-language rule), voice-and-tone.md, terminology.yaml, app.md |
| App UI visuals | visual-system.json, logo.md, app.md |
| Photo or AI image brief | art-direction.md, art-direction-graphics.md, visual-system.json, constraints.yaml |
| FAQ / science page (teaching layer) | constraints.yaml, voice-and-tone.md (the “Short” exception), terminology.yaml, messaging-objections.md |

## Review

- All customer-facing output goes to human review before publishing, and agent output lands in staging.
- Never paste customer-identifiable information or individual health data into an agent.
- Never paste Neuvana Health or Neuvalo material into the same agent project as this kit.
