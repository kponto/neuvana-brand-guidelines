# Logo

## Mark

Solid line mark only. Do not use the gradient version. The gradient treatment is experimental and not approved for general use.

The mark is a lotus-form line symbol. It is fixed for now. Kevin did not design the original logo and can only modify it, not replace it.

## Assets

All files are in `visual/assets/`. Cloud versions are light (for dark backgrounds). Tar versions are dark (for light backgrounds).

| File | Use |
|---|---|
| `neuvana-logomark-cloud.svg` | Logomark only, light |
| `neuvana-logomark-tar.svg` | Logomark only, dark |
| `neuvana-logotype-cloud.svg` | Wordmark only, light |
| `neuvana-logotype-tar.svg` | Wordmark only, dark |
| `neuvana-logo-horizontal-lockup-cloud.svg` | Mark + wordmark side by side, light |
| `neuvana-logo-horizontal-lockup-tar.svg` | Mark + wordmark side by side, dark |
| `neuvana-logo-vertical-lockup-cloud.svg` | Mark stacked above wordmark, light |
| `neuvana-logo-vertical-lockup-tar.svg` | Mark stacked above wordmark, dark |

## Usage

- Solid line mark on light or dark fields.
- Keep the mark small and infrequent in marketing layouts, not centered and hero-sized, unless the format specifically calls for it (app icon, lockup on banners).
- Coral appears in the app only within the logo. This is an app rule, not a marketing rule.
